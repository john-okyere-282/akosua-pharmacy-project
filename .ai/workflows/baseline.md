# Workflow: Baseline Capture

1. Verify JDK 21 and Maven environments.
2. Compile and run original `PharmacyTracker.java` using javac and java commands.
3. Compile and run using Maven (`mvn exec:java`).
4. Save original stdout to `baseline/original-output.txt`.
5. Populate `.ai/context/baseline-behaviour.md` with detailed behavioral analysis.
6. Classify each behavior as PRESERVE or FIX.
