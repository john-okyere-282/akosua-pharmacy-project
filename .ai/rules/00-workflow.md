# Workflow Rules

- **HARD RULE**: No file under `src/` may be edited until `DIAGNOSIS.md` is committed.
- Commit small and often, using conventional commit messages (`refactor:`, `test:`, `docs:`, `chore:`).
- One concern per commit. Never mix refactoring and behavioral changes in the same commit.
- Before any non-trivial step, state the plan and obtain approval.
- Keep the `.ai/` directory uncommitted and gitignored.
