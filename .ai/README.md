# Agent Context & Rules Index

This directory maintains reference context, rules, skills, workflows, and role descriptions for the refactoring of Akosua's Pharmacy.

## Structure
- `context/`: Lab brief, domain requirements, and baseline execution logs.
- `rules/`: Workflow, Java style, behavior preservation, and decision transparency standards.
- `skills/`: Tooling guidelines for diagnosis, design records, diff generation, and defense drills.
- `workflows/`: Step-by-step guides for baseline capture, diagnosis, ADR authoring, building, verification, and defense prep.
- `agents/`: Specialised personas (Architect, Implementer, Reviewer, Examiner).
