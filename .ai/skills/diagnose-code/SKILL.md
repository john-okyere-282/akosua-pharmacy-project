# Skill: diagnose-code

## When to use
Use during codebase diagnosis to evaluate bugs, architectural weaknesses, security/business risks, and ranking by operational danger.

## Steps
1. Trace execution and state mutations from entry points.
2. Identify code locations violating invariants, encapsulation, or business rules.
3. Determine root cause and classify severity (Critical, High, Medium, Low).
4. Rank by business danger to a real pharmacy.

## Output Format
Markdown report detailing: Problem, Code Location, Root Cause, Business Risk, Severity, and Recommended Remediation.
