# Skill: design-decision

## When to use
Use when choosing between architectural or design patterns (e.g. polymorphism vs enums, error reporting strategies).

## Steps
1. Frame the problem and design requirements.
2. Present 2 to 3 viable options.
3. Compare on maintainability, cognitive overhead, and ease of extending.
4. Record choice, rationale, and accepted trade-off as an ADR.

## Output Format
Standard Architecture Decision Record (`ADR-00X-<title>.md`) written in first person.
